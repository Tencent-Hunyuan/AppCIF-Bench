## 一、八纲辨证关键词

### 1.1 表里辨证

#### 里证（脏腑症状）
| 关键词 | 说明 |
|--------|------|
| 心慌、心悸、胸闷、失眠、多梦、舌尖痛 | 心系症状 |
| 咳嗽、气喘、咳痰、胸痛 | 肺系症状 |

| 尿频、尿急、尿痛 | 膀胱症状 |
| 便秘、腹泻、拉肚子 | 大肠症状 |

**严重程度词（触发里证）**：严重、剧烈、很疼、巨疼、疼得厉害

## 二、危症关键词

### 2.1 亡阳证
**必须同时满足：寒证 + 以下3类症状全部存在**

| 类别 | 关键词 |
|------|--------|
| 冷汗类 | 冷汗、汗出如珠、大汗淋漓 |
| 肢冷类 | 四肢冰凉、手脚冰凉、肢体厥冷 |
| 面色类 | 面色苍白、面色惨白、唇色发紫 |

**必须同时满足：热证 + 以下3类症状全部存在**

| 类别 | 关键词 |
|------|--------|
| 大汗类 | 大汗（非冷汗） |
| 口渴类 | 口渴、渴喜冷饮 |
| 手脚热类 | 手脚发热、四肢温热 |

### 2.3 气脱证
**满足 ≥2 个症状，或气虚证 + 任意1个症状**

| 关键词 |
|--------|
| 精神萎靡 |
| 瞳孔散大 |
| 呼吸微弱 |
| 大便失禁 |
| 小便失禁 |
| 手撒、握不住 |

## 十一、出题建议

### 11.1 按病症类型出题

1. **危症题**：组合冷汗/大汗 + 肢冷/肢热 + 面色/口渴
2. **脏腑病题**：脏腑定位词 + 八纲证型词
3. **七情题**：情志极端词 + 因果关系 + 脏腑症状
4. **六淫题**：季节 + 外邪特征词

### 11.2 按难度出题

1. **简单**：单一证型，关键词明确
2. **中等**：组合证型，需要推导
3. **困难**：真假寒热/虚实，需要综合判断
